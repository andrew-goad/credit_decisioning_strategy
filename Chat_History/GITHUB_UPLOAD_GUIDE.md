# Add Chat_History at the CDS repository root

The ZIP contains exactly one top-level folder: `Chat_History/`.

1. Extract the ZIP. Keep the folder name and all nested paths intact.
2. Copy `Chat_History/` into the root of `andrew-goad/credit_decisioning_strategy`, alongside the existing Module 1 and Module 2 folders. Do not place it inside either module.
3. Upload/commit the complete extracted tree. For a large file set, GitHub Desktop or a local Git checkout preserves the structure more reliably than selecting individual files in the web uploader.
4. Open `Chat_History/README.md` on GitHub and follow the handoff reading guide. Confirm the links open before sharing the case study companion.
5. Add the following line to the existing root README, without replacing its current content:

```markdown
## Development history

[Read the CDS chat history](Chat_History/README.md), including the handoff preparation, 13 response audits, campaign QA, reporting and later evidence reviews.
```

The case study presentation and slide metadata belong in the personal portfolio repository. They are intentionally outside this CDS upload ZIP. The companion links to `https://github.com/andrew-goad/credit_decisioning_strategy/blob/main/Chat_History/` and will resolve after this folder is uploaded to main. For permanent release references, replace `main` with the actual resulting commit SHA after upload; do not guess a future SHA.

The archive includes a checksum manifest. No existing Module 1 or Module 2 file needs to change.
