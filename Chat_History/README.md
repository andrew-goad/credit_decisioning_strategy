## Reading and evidence boundaries

The Markdown files render on GitHub. For the black-and-white conversation treatment, download the folder and open [Reader/index.html](Reader/index.html) locally; GitHub displays HTML source rather than hosting this reader. Full JSONL records support text search and audit.

“Complete” refers to visible exported text for the declared full project conversations. Image-only content and most attachments are represented by metadata, not recovered bytes. The final capture prompt is a separately recovered attachment. Internal reasoning records are excluded. Original source identities, all branch links, text hashes, sanitation categories and coverage are recorded in the companion indexes.

Conversation history shows proposals, corrections and decisions at the time. The repository’s retained SQL, QA outputs, validation documents and release records support the final technical results. Historical assistant approval is not a substitute for those artifacts.
